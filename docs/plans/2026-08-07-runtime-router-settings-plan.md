# Runtime Router Settings Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Load model/provider-specific outbound headers from a runtime JSON file selected by `EXHUB_ROUTER_CONFIG` or `~/.config/exhub/router.json`, without recompilation.

**Architecture:** Keep `Exhub.Router.Config.get_auth_headers/2` as the header composition boundary. Add a small runtime settings reader with file metadata caching and explicit cache invalidation; merge validated JSON rules over generated auth headers while protecting authorization headers. Use glob model matching and provider filtering.

**Tech Stack:** Elixir, Jason, ExUnit, Plug.Router, `File.stat/1`.

### Task 2: Implement runtime JSON settings reader

**Files:**
- Create: `lib/exhub/router/settings.ex`

**Step 1: Implement path resolution**

Add `path/0` that returns `EXHUB_ROUTER_CONFIG` when non-empty, otherwise `Path.join(System.user_home!(), ".config/exhub/router.json")`.

**Step 2: Implement safe loading and caching**

Add `headers(model, provider)` and `reload/0`. Cache the parsed rules and file metadata in an ETS table or process-safe module state; avoid a permanent GenServer dependency if a metadata-aware cache is sufficient. Re-read when the file mtime/size changes. Missing files return `[]`; malformed JSON or invalid rule shapes log a warning without exposing header values and return `[]`.

**Step 3: Implement matching and validation**

Accept rules shaped as `models`, `providers`, and `headers`. Treat omitted model/provider lists as unrestricted. Match case-insensitively. Implement `*` glob matching by converting the pattern to a safe regex; do not evaluate arbitrary expressions. Require string header names and values. Ignore `authorization`, `x-api-key`, and equivalent case-insensitive credential headers from JSON.

**Step 4: Run tests**

Run: `rtk mix test --no-start test/exhub/router/settings_test.exs`

Expected: PASS.

**Step 5: Commit**

Run: `rtk git add lib/exhub/router/settings.ex test/exhub/router/settings_test.exs && rtk git commit -m "Add runtime router settings reader"`
